# MCP örnek yapılandırmaları

- `claude_desktop_config.json`: Claude Desktop için. `KULLANICI` yerine Windows kullanıcı adınızı yazın
  (tam yol Etiket Tasarım → Yapay Zekâ → Ayarlar → Bağlantı bilgileri bölümünde hazır gösterilir) ve içeriği
  `%APPDATA%\Claude\claude_desktop_config.json` dosyasına ekleyin.
- Claude Code: `claude mcp add --scope user akel-etiket -- "<kurulum klasörü>\AkelEtiket.Mcp.exe"`

Ayrıntılar: Belgeler\YAPAY-ZEKA-BAGLANTI.md
