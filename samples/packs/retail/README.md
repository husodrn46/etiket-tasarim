# Retail starter pack

Use the retail product or shelf template. Load sample.csv in Data, review the mapping, then replace the sample rows. Price is raw text without an assumed currency. DEMO barcodes are internal examples, not assigned GS1 identifiers.

Add templates from the Templates panel → Starter packs. Preview at your printer resolution and run a small physical test before production. UI language does not translate your data. All included data is fictional.
