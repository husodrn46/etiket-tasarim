# Mağaza başlangıç paketi

Mağaza ürün veya raf şablonunu ekleyin. Veri panelinden sample.csv dosyasını açıp eşleştirmeyi kontrol edin. Fiyat ham metindir; para birimi varsayılmaz. DEMO barkodları GS1 tahsisi değildir.

Şablonlar → Hazır kullanım paketleri bölümünden ekleyin. Yazıcı çözünürlüğünde önizleyin; gerçek üretimden önce küçük bir fiziksel test yapın. Arayüz dili verinizi çevirmez. Örneklerin tamamı sentetiktir.
