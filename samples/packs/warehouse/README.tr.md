# Depo başlangıç paketi

Stok ve konum şablonlarını sample.csv ile kullanın. SKU ve Location alanlarını kendi iç kodlarınızla değiştirin. Code 128 iç kodları GS1 tahsisi oluşturmaz. Baskı adedini kontrol edin.

Şablonlar → Hazır kullanım paketleri bölümünden ekleyin. Yazıcı çözünürlüğünde önizleyin; gerçek üretimden önce küçük bir fiziksel test yapın. Arayüz dili verinizi çevirmez. Örneklerin tamamı sentetiktir.
