# Warehouse starter pack

Use the stock and location templates with sample.csv. Replace SKU and Location with your own internal codes. These Code 128 identifiers do not require or create a GS1 allocation. Check quantity before printing.

Add templates from the Templates panel → Starter packs. Preview at your printer resolution and run a small physical test before production. UI language does not translate your data. All included data is fictional.
