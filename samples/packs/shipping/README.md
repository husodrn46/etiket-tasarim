# Shipping starter pack

Use the full or compact shipping template with sample.csv. Replace recipient and address, and obtain the actual tracking number from your carrier. The DEMO code does not create a shipment or carrier booking.

Add templates from the Templates panel → Starter packs. Preview at your printer resolution and run a small physical test before production. UI language does not translate your data. All included data is fictional.
