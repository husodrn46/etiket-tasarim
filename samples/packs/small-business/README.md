# Small business starter pack

Use the batch template with sample.csv or edit the static asset label. Replace product, batch, date and internal inventory identifiers. This is a generic layout, not a regulatory or certification template.

Add templates from the Templates panel → Starter packs. Preview at your printer resolution and run a small physical test before production. UI language does not translate your data. All included data is fictional.
